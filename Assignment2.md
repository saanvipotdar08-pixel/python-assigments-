**Logical Operators in Python: and, or, not**

Logical operators are used to combine or evaluate multiple conditions and give a result in True or False.

1.and– Returns True only when both conditions are true. If any one condition is false, the result is false. For example, checking if a number is greater than 0 and less than 10 will be true only if both conditions hold.

2.or– Returns True if at least one of the conditions is true. It gives false only when both conditions are false. For example, checking if a number is less than 0 or greater than 100 will be true if either one condition is satisfied.

3.not– Reverses the result of a condition. If the condition is true, not makes it false, and if the condition is false, not makes it true. For example, not applied to a true condition gives false, and not applied to a false condition gives true.
