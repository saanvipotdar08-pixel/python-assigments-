Aim:
Write a Python program that accepts the length of three sides of a triangle as inputs. The program should indicate whether or not the triangle is a right-angled triangle using function. 

**1. What is a Function in Python Programming?**

A function is a reusable block of code written to perform a specific task, so the same code doesn't need to be written again and again. It is defined using the `def` keyword and is called by its name whenever needed. Functions make programs shorter, organized, and easier to debug.

**2. Is it Mandatory for a Python Function to Return a Value?**

No, it is not mandatory. A function can work without a `return` statement, in which case Python returns `None` by default. Return is only used when the result is needed for further use.

**3. Name some standard Python errors.**

Some common Python errors are SyntaxError, NameError, TypeError, ValueError, IndexError, KeyError, ZeroDivisionError, and IndentationError.
